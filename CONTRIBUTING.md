# Contributing

## Before writing

1. Choose the closest topic under `content/`.
2. Search for overlapping material before creating a file.
3. Use a descriptive lowercase kebab-case filename.

## Recommended article shape

1. Interview question or concept
2. Concise answer
3. How it works internally
4. Trade-offs and alternatives
5. Failure modes and production concerns
6. Code or design example
7. Follow-up questions
8. References

## Pull-request checklist

- Markdown is the source of truth.
- Claims and code examples have been checked.
- Examples identify relevant Java/framework versions.
- Diagrams have readable source files where practical.
- No credentials, private data, generated indexes, or local configuration are included.
- Generated PDFs, if published, match the current Markdown.
